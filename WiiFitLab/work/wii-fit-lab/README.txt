Wii Fit Lab v0.9.0
==================

バランスWiiボードの体重・4隅の荷重・重心位置をリアルタイム表示する
Windows 11向けアプリです。ボード内部の温度・工場基準温度・電池残量と、
温度補正前後の重量も確認でき、測定値をCSVファイルへ記録できます。

起動方法
--------
1. WiiFitLab.exe をダブルクリックします。
2. ボードが消灯していたら、前面の電源ボタンを押します。
3. 「接続済み」になったら、平らな床で何も載せず「ゼロ調整」を押します。
4. 転倒しないよう、壁や手すりにつかまってボードへ乗ります。

CSV記録
-------
「CSV記録を開始」を押して保存先を選びます。経過時間、日時、合計荷重、
温度補正前後の重量、4隅の荷重、左右・前後の重心位置、温度・基準温度・
電池の生値、4センサーの16-bit生値を通信レポートごと（実機確認では
約100回/秒）に保存します。

技術モニター
--------------
「技術モニター」を押すと、各センサーの生値、個体別の0/17/34 kg工場校正点、
区間ごとの感度、実測受信周波数、重量・重心・温度の直近60秒波形を表示します。

疑似ペダルモード
------------------
座った状態で左足をブレーキ、右足をアクセルとして使えます。「基準」「左最大」
「右最大」の順に校正し、表示のみで動作確認してから出力を有効にしてください。
キーボード出力では右足がW、左足がSです。vJoy導入済み環境ではZ軸をアクセル、
Rz軸をブレーキとしてアナログ出力できます。信号が250ms途切れた場合や画面を
閉じた場合は、押下中のキーとvJoy出力を自動解除します。

ミニゲーム
----------
「ミニゲーム」からドライブ、ブロック崩し、ホバーレース、3Dバランステーブル、
サイドスタンス・スノーを選べます。
すべて外部ゲームへ
キー入力を送らず、このアプリ内だけで動作します。

簡易ドライブシミュ
------------------
ドライブでは、外部ゲームへ入力を送らずにペダルを試せます。左足が
ブレーキ、右足がアクセル、←→またはA/Dがハンドルです。速度・走行距離・空気
抵抗・転がり抵抗・路肩での追加減速を持つ簡易2Dテストコースです。ペダルを
3ステップ校正してから「走行開始」を押してください。Rキーで道路中央へ戻れます。

バランス・ブロック崩し
------------------------
ボード上で左右へ重心を移すとパドルが動きます。前面Aボタン、SpaceまたはEnterで
ボールを発射します。←→またはA/Dでも操作できます。パドルの端で返すほど斜めに
飛び、左右感度は1.0〜3.0倍を0.1刻みで調整できます。全ブロックを消すと速度が
上がった次のレベルへ進みます。Pで一時停止、Rで最初からやり直せます。

ネオン・ホバーサーキット
--------------------------
固有作品の素材を使用しない、近未来ハイスピード・タイムアタックです。中心姿勢を
記録した後、前傾で加速、後傾でブレーキ、左右傾きで操舵します。前面Aボタンで
エネルギーを消費してブーストします。WASD/矢印とSpaceでも操作できます。紫の
障害物を避け、青いブースト床を狙って最高速と走行距離を伸ばします。

3Dバランス・テーブル
----------------------
固定カメラで見る厚みのある浮遊3D盤面そのものを前後左右へ傾け、重力と慣性で
黒・白・赤の球を転がして穴へ入れます。クリーム色のタイル面、茶色い側面、
立体障害物、複数球の衝突を持つ全5レベルです。中心姿勢を水平として記録してから
開始します。感度は1.0〜3.0倍、矢印またはWASDでも操作できます。

サイドスタンス・スノー
------------------------
Balance Boardをテレビに対して90°回し、長い方向へ前足と後ろ足を置きます。
自然に立った姿勢を記録した後、つま先／かかと荷重でカービング、前足荷重で加速、
後ろ足荷重で減速します。レギュラー／グーフィーと旋回反転に対応しています。
ゲート、木、ジャンプ台がある75秒コースです。安全のためボード上では跳ばず、
ジャンプ台に乗るとゲーム内のキャラクターが自動でジャンプします。

再接続
------
通常はSYNCボタンを使いません。アプリを起動し、ボード前面の電源ボタンを
押してください。接続されない場合は「接続する」を押します。

初回ペアリングをやり直す場合
----------------------------
同梱の Pair-WiiBalanceBoard.ps1 をPowerShellから実行し、電池ぶた内の
赤いSYNCボタンを押します。

注意
----
- 医療診断・治療・商取引には使用しないでください。
- 温度値は通信プロトコル上の未公開生値で、摂氏に近いものの保証値ではありません。
- ペダルモードは必ず椅子に座り、ボードを平らで滑らない場所へ置いて使用してください。
- 立って遊ぶ場合は、壁や手すりに手が届く安全な状態で小さく重心移動してください。
- 任天堂の公式ソフトウェアではありません。
- Wii、Wii Fit、Nintendoは任天堂の商標です。

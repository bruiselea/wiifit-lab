Wii Balance VR Bridge v0.1.0
================================

Balance Boardの荷重をVRChat公式OSC移動入力へ変換する専用Windowsアプリです。

使い方
------
1. Balance Board前面の電源ボタンを押します。
2. VRChatの Action Menu > Options > OSC > Enabled をONにします。
3. Bridgeで歩行・スキー・スノーボードを選択します。
4. ボードに乗り「現在の姿勢を記録」を押します。
5. 「VRChat出力ON」を押します。F12で常に緊急停止できます。

モード
------
F8 歩行: 通常向き。左右へ交互に荷重すると前進します。
F9 スキー: 通常向き。左右でカーブ、前後で加減速します。
F10 スノーボード: ボードを90度回します。エッジでカーブ、前足・後ろ足で加減速します。

OSC
---
VRChat公式の /input/Vertical と /input/Horizontal だけをUDP送信します。
通常はOSCQueryで自動検出し、見つからない場合は127.0.0.1:9000を使用します。
vJoy、キーボード注入、仮想トラッカーは使用しません。

安全
----
滑らない平らな床で、壁や手すりに手が届く範囲に設置してください。
ボード上でジャンプしないでください。モード切替、切断、信号停止、終了時はOSCを0へ戻します。
